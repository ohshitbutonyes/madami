# Madami — сайт

Статичный одностраничник: `index.html`, `styles.css`, `main.js`, фото в `img/`.
Локально: `python3 -m http.server 8417` в корне репозитория → http://localhost:8417

## Откуда что взято
- **Визуал** — `MOODBOARDS/`: небо и луг, срезы дерева (мотив кольца), кремовые и песочные тона, акцент цвета подпала гросса.
- **Структура** — `02_RESEARCH` (CJM, конкуренты) и `03_INSIGHTS` (сегменты M8, драйверы доверия M9, инсайты M10):
  три входа по сегментам S1/S2/S3, доказательства вместо обещаний, «кому подходит / о чём честно знать», 7 шагов покупки, поддержка после покупки, короткая заявка.
- **Тексты, собаки, помёты, контакты** — PDF «Из Дома МаДаМи».
- **Фото** — извлечены из того же PDF (оригиналы в `ASSETS/pdf_photos`).

## Что нужно от питомника перед запуском
- Актуальный помёт и статусы щенков (сейчас последний — 21.11.2025, статусы убраны как устаревшие).
- Какая фотография какой собаке принадлежит — тогда в карточки производителей можно добавить фото.
- Заключения HD/ED для ESTEL, TONIKA, SORBONNA, SANSHAIN (в PDF их нет).
- Цена или диапазон и условия брони/задатка (по M9 — сильный драйвер доверия).
- Истории выпускников с разрешением на публикацию.
- Бэкенд для формы: сейчас она собирает письмо в почтовый клиент (mailto).

## Блок для Tilda
`python3 tools/build_tilda.py` собирает `tilda-block.html` — весь сайт одним блоком T123.
Фото подгружаются из папки, заданной в `const IMG` в начале скрипта блока.
